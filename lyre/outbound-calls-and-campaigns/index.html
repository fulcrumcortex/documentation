Outbound calls, objectives and campaigns in Lyre

Place a one-off outbound call with a Lyre agent, set reusable objectives that qualify leads, and run call, SMS or email campaigns across a list of recipients.

Lyre agents can call people as well as answer. You can place a single call, give the agent a reusable objective that says what the call should achieve, or run a campaign across a whole list. Before you start, make sure the agent has a phone number and you've read calling hours and do-not-contact rules.

Place a one-off call

  1. Open Calls and select New outbound call.
  2. Choose the Agent and, optionally, an Objective. Without one, the agent uses its default persona.
  3. Check Call from. The agent needs a phone number attached.
  4. In Call to, search for a name or number, or type a number such as +61412345678. Add a Name if you like.
  5. Select Dial.

Set an objective

An objective is a reusable goal for outbound calls, such as qualifying a new enquiry or confirming an appointment. Open Objectives and fill in:

  • Name and Goal: what a successful call looks like.
  • Information to collect: the answers you need, such as budget, timing or decision-maker. This is how Lyre qualifies a lead.
  • Guardrails: what the agent must not say or do.
  • Opening line: you can personalise it with {{name}}, {{agent_name}}, {{date}} and {{time}}.

Select Create objective. Then choose it on a one-off call or a campaign.

Run a campaign

  1. Open Campaigns and select New campaign.
  2. Give it a Name and choose the Channel: call, SMS or email.
  3. Under Agent & number, pick an outbound number that has an agent assigned.
  4. For calls, set Concurrent calls, which is how many calls run at a time (1 to 10).
  5. Choose the Objective, an optional Category, and the Recipients.
  6. Under Schedule, choose Send now or Schedule a start time. Scheduled times use your local time.
  7. Optionally enter a Report email to have the campaign report sent by email.
  8. Select Create & run, or Schedule campaign if it starts later.

Open a campaign to follow each recipient's Status, Outcome and attempt time. From there you can open the Campaign report or select Cancel campaign to stop it.

Campaigns only call within your organisation's calling hours. The Override calling hours option is only for testing or for contacts who have agreed to be called; see Compliance.

Multi-step journeys

For outreach with several steps and branches, use Journeys. Select New journey to design the flow on a visual canvas.

How Lyre records the result

After each call, Lyre classifies the outcome. Examples are Booking made, Lead captured, Not the decision maker, Not interested, Callback requested, Do not call and Escalated to human. Outcomes and quality scores appear in call history. You can use them to decide who to follow up first. If your team works the leads in a CRM, Fulcrum CRM can place Lyre calls from a contact record and logs each call on the timeline.
