Fulcrum Mail settings

Set up email signatures, appearance, notifications and your profile in Fulcrum Mail, import mail from Zoho, and install Fulcrum Mail as an app.

Open Settings to change how Fulcrum Mail looks and behaves. This guide covers the settings most people use. Security settings, such as two-step verification, are in Create an account and sign in.

Email signatures

  1. In Settings, open Email signature and select New signature.
  2. Give it a Signature name and design it in the Visual editor, or paste HTML in Source (HTML).
  3. Select Save signature.
  4. Under Defaults, choose which signature to use For new messages and For replies and forwards.

While you're writing, Insert signature in the compose toolbar switches signatures or removes them with No signature.

Appearance and reading layout

Under Appearance, choose Light, Dark or System. For the reading layout, pick Split view to keep the message list beside the open email, or Full-width view to show the email alone.

AI mail experience

Fulcrum Mail can summarise and read mail to you. Under AI mail experience you can:

  • Turn on Use Focus feed on mobile. The Focus feed is a card-by-card catch-up view for phones with Listen to summary, Reply to message and Archive message on each card.
  • Turn AI generated cards and Autoplay in Easy Mode on or off.
  • Choose a Reading voice and use Preview voice to hear it first.

Notifications

  1. Open Notifications and turn on Notifications on this device.
  2. Under Notify me about, choose New email in your inbox, Calendar invitations and changes, or both.
  3. Select Send test notification to check that it works.

On an iPhone or iPad, add Fulcrum Mail to your Home Screen first (see below). Notifications need iOS 16.4 or later.

Import mail from Zoho

If your old mailbox is with Zoho Mail, you can copy it into Fulcrum Mail from Settings.

  1. In Zoho, create an app-specific password. Don't use your normal Zoho sign-in password.
  2. In Fulcrum Mail Settings, open Import from Zoho.
  3. Enter your Zoho mailbox address and the Zoho app password.
  4. Select Scan mailbox to check the connection and scan your Zoho folders.
  5. Select Import mail. You can Pause import and Resume import at any time. When it finishes, the panel shows Import complete.

Moving a whole team from Microsoft 365 or Google Workspace is a bigger job. The guide to moving business email to Fulcrum Mail covers it.

Profile and language

Under Profile, set your Full name, Job title and Contact phone, then select Save profile. Language switches the interface between English, Italiano and 简体中文. Connected calendars links Google and Microsoft calendars; see Import and connect calendars.

Install Fulcrum Mail as an app

Fulcrum Mail runs in the browser and can also be installed so it opens in its own window.

  • Browsers that support installing apps: select Install on the Install Fulcrum Mail banner, or Install app in Settings.
  • iPhone and iPad: in Safari, tap Share, then Add to Home Screen, then Add.
  • Mac with Safari: choose File → Add to Dock.

To see what changed in recent releases, select View changelog at the bottom of Settings or read the Fulcrum Mail changelog.

Change one setting and verify it

Send a test message to an address you control after changing a signature. For notifications, check both Fulcrum’s preference and the browser or operating system permission. A preference can be enabled in the app while the device still blocks delivery.

Before importing mail

Check the source mailbox, destination account and available storage. An import copies supported mail; do not assume it replaces ongoing delivery or configures your domain. Review a small sample of imported folders, dates and attachments before relying on the result.
