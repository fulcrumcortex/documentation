Fulcrum Code: your coding teammate

Get started with Fulcrum Code: install the terminal coding agent, sign in, choose a model, plan a change and verify the result in your project.

Fulcrum Code is the terminal coding agent in the Fulcrum family. It can investigate a repository, edit files, run commands and tests, use code intelligence, and delegate focused work to subagents. You work in your own project directory and describe the outcome in plain language.

What you need

  • A Fulcrum account and access to the model service.
  • A supported macOS, Linux or Windows installation.
  • A project folder you are authorised to work on. A Git repository gives you a practical way to review and recover changes.

Your first useful task

  1. Follow Install and sign in, then open your terminal in the project folder.
  2. Run fulcrum. Enter /models to choose from the managed model catalogue.
  3. Enter /plan, then ask: “Find where this project validates form input. Explain the current behaviour and propose the smallest improvement. Wait before editing.”
  4. Read the plan. When you are ready, enter /build and describe the change to make.
  5. Ask the agent to run the relevant checks. Review the diff and the reported results before committing or publishing.

What counts as finished?

An edited file, a passing test, a Git commit and a live deployment are separate outcomes. Tell the agent which you need and ask for evidence at each stage. For example: “Make the change and run the focused tests; stop before publishing.” If you need a release, explicitly include publication and live verification in the request.

Fulcrum Code is the coding tool. Fulcrum Sessions orchestrates humans and AI across work, while Code inside Cortex explains the wider business use.
