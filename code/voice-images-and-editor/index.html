Voice, images, themes and VS Code

Use voice input and spoken replies in Fulcrum Code, add image context, adjust themes and keybindings, and work from the VS Code extension.

Speak a request

/voice records microphone input for transcription. Allow microphone access in your operating system, speak your request and review the transcript. Names, file paths and commands can be misheard; correct them before letting the agent act.

Hear the response

/speak speaks a response; /speak-on and /speak-off control spoken replies. /voices opens the voice picker. Check output volume and consider who can hear sensitive content around you.

Give visual context

Paste a clipboard image into the prompt to discuss a layout or visual problem. /vision controls the vision model. Describe what should be compared or changed, and crop account names, browser tabs, tokens and unrelated windows out of the image before sharing it. Image analysis depends on a vision-capable model being available.

Set up the terminal

CommandPurpose
/themeList and choose themes, including Fulcrum Amber, Midnight, Mono and Forest
/vimToggle Vim-style prompt editing
/keysShow keyboard shortcuts
/keys editEdit the keybinding override file
/keys resetRemove custom bindings
/config-pathFind the preferences file

Preferences live under ~/.fulcrum/. Restart after changing keybindings. If a shortcut stops working, check the terminal's own bindings as well as Fulcrum's.

Work from VS Code

The Fulcrum Code extension adds an activity-bar panel and actions to send selected code, mention a file and make one-shot requests. Follow the extension's installation instructions for your release. Check the active project and selected text before sending context. Use the terminal agent when you need the complete interactive workflow.

Get help

/help lists the installed commands. Include /version and a redacted error when reporting a problem. Current models, extension packaging and operating-system permissions can differ between installations.
