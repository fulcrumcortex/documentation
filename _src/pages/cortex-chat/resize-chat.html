The divider supports pointer and keyboard resizing, while the floating panel has its own resize grip. Resizing should improve workspace room without changing which assistant or app is active.

Before you start

Appearance, layout, notification sounds and some cached history are device/browser state. The interface explicitly marks a conversation background as This device and distinguishes an account-saved default Sidekick from a cached value. Another participant or device may therefore look different without anything being broken. A cached conversation is useful while reconnecting but does not prove that identity is currently verified or that a new message reached the server. Preserve useful drafts before clearing browser storage. When troubleshooting, distinguish browser permission, local preference, network availability and external service state instead of treating them as one setting.

Step-by-step

  1. Locate Resize Sidekick chat on the docked divider, or Resize floating chat on the floating panel.
  2. Drag to the desired size, or focus the control and use arrow keys.
  3. Check that the composer, app and settings controls remain usable after the change.

What the settings mean

Control or stateMeaning
Device preferenceA setting whose effect is local to this browser or device.
Account preferenceA value confirmed as saved to the signed-in account.
Cached historyPreviously stored conversation content, not a new server result.
Browser permissionMicrophone, sound or notification authority outside the app switch.

Check the result

The panel fits your workspace and retains the intended conversation.

If it does not work

If the window is narrow, use the mobile/list layout rather than forcing a desktop width. A clipped panel may be a layout issue, not missing data.
