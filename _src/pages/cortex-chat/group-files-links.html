Files and Links are separate group-content views. A link can lead outside Cortex and can contain private access tokens or reservation controls, so it should be treated according to its purpose.

Before you start

A direct conversation, a group and the private Ask a Sidekick panel are different audiences. Joining a group does not make someone a workspace administrator, and sharing an external file in a group does not override that file’s own access rules. Use names, membership and account context to confirm the intended conversation before sending. When inviting someone, distinguish an invitation that was created from one that was accepted. A public-looking display name is not enough to resolve an ambiguous recipient. Where a Sidekick helps draft a group response, decide separately whether the proposed text should actually be posted to the shared conversation.

Step-by-step

  1. Open the group’s information and choose Files or Links.
  2. Inspect the name or destination before opening the item.
  3. Verify that the external destination and its account context are the ones you expect.

What the settings mean

Control or stateMeaning
Direct conversationA conversation with the selected person.
GroupA shared thread governed by its membership and settings.
Private assistanceThe separate Ask a Sidekick surface.
External linkA destination that retains its own access and expiry rules.

Check the result

The intended file or destination opens without exposing the link to an unintended audience.

If it does not work

If a shared file is unavailable, check its independent sharing permissions or expiry. Membership in the group does not automatically grant access to every external file.
