Cortex Chat combines private Sidekick conversations, conversations with people, groups and connected applications. The selected item changes both the visible history and the context in which an assistant acts; the sidebar is more than a list of interchangeable chat windows.

Before you start

Check three separate layers: the identity signed in through Fmail, the Sessions workspace supplying the Sidekick, and the app connection supplying the requested data. One working layer does not prove the others are ready. Start with a harmless read or a draft before asking for an external change. A message to an assistant can contain instructions and source material, but permissions come from the saved account and tool settings. When an operation is unclear, describe the required outcome and ask the assistant to identify the missing stage instead of changing several settings at once.

Step-by-step

  1. Open https://chat.fulcrumcortex.com/ and sign in if asked.
  2. Locate Sidekicks, People & groups and Connected Apps in the workspace navigation.
  3. Open one item from each section and check the heading before returning to your intended conversation.

What the settings mean

Control or stateMeaning
AccountWho is signed in and which personal or company context is being used.
SidekickThe selected assistant and its runtime availability.
ApplicationThe connected service and the account it uses.
OutcomeThe artifact or destination record that establishes completion.

Check the result

You can identify the current conversation, assistant and app before sending anything.

If it does not work

If a section is hidden on a phone, return to the workspace list and use its section controls. Do not assume a hidden sidebar means your data was deleted.

Continue with the right context

Return to the Cortex Chat guide index to choose another task. Keep the current account, assistant and conversation in view when following the next guide. To use the product, open Cortex Chat.
