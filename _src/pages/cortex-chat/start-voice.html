The Lyre panel can show whether voice is inactive, ready or needs attention. Microphone capture starts through your deliberate start action; a decorative voice surface is not an active call.

Before you start

Choosing a voice, activating the profile and starting a conversation are separate stages. A voice catalogue can load while activation fails. An activated profile can still be unable to start because the service reports a readiness or credits issue. The microphone and playback permissions introduce another layer when an actual session begins. Read the current status and the specific error at the stage where it occurs. Do not blame microphone settings for a failed activation request before capture has even started. Review the intended Sidekick profile before opening advanced Lyre settings, and reconcile an uncertain configuration or payment result before repeating it.

Step-by-step

  1. Choose the intended Sidekick and open Lyre or the live-voice control.
  2. Confirm voice is activated and ready, then select Start conversation.
  3. Grant microphone access if requested and observe the session moving from getting ready to its active state.

What the settings mean

Control or stateMeaning
Voice choiceThe selected catalogue entry, which still needs saving.
ActivationThe saved enabled state for the selected voice profile.
ReadinessWhether the service currently allows a session to start.
Live sessionThe actual connecting, listening, speaking and ended interaction.

Check the result

The intended Sidekick has an active voice session and you can verify an actual exchange.

If it does not work

If the button is unavailable, inspect offline, loading, saving, credits and readiness guidance. Do not mistake a connected chat account for a working audio session.
