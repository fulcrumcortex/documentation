SMS alongside a call

Use SMS in the dashboard to inspect messages. Voice agents can send SMS when their enabled tools, instructions and phone configuration support it. Tell the agent what may be sent, such as an agreed booking link, and verify the recipient and message outcome in the history. A completed call does not prove an SMS was delivered.

Contacts and caller context

Contacts stores people used in calling workflows. Check the international-format phone number and contact details before calling or adding a person to a campaign. A recognised caller can provide useful context, but should not be treated as verified identity for sensitive changes.

Knowledge Base

Create a knowledge base, upload the supported files and wait for each file to become Ready. Pending and Processing mean the content is not ready yet; Failed needs investigation. Attach the knowledge base in the agent's Tool access tab and save. Ask a question whose answer exists only in that material to verify retrieval. Re-test after replacing outdated content.

Skills

A Lyre skill has a name, a When to use description and Markdown instructions. Use it for a focused playbook, such as gathering details for a callback. Knowledge supplies facts; a skill supplies the procedure. Give the skill a clear completion rule and escalation path rather than a vague instruction to “handle everything.”

Connections

Use Connections to manage supported external service connections. Complete the provider's sign-in and consent flow with the intended account, then verify the specific action you need. Calendar sign-in, calendar availability and event creation are distinct capabilities. See Booking meetings.

Team and organisation settings

Organizations manages membership. Use the intended organisation before inviting a colleague, changing a connection or inspecting billing. Share the appropriate role rather than sharing one person's login. Keep provider credentials out of prompts and screenshots.

Verify an end-to-end workflow

  1. Use your own approved test contact and number.
  2. Ask the configured agent a question from the knowledge base.
  3. Request an allowed follow-up action, such as sending a link or making a booking.
  4. Review the transcript, message status and destination record.
  5. Correct instructions or permissions and repeat the focused check before wider use.

Use the current dashboard for availability and service status. These resource features complement voice agent setup and call review.
