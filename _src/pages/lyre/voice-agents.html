An agent is the voice that answers and places your calls. You give it a name, a role, an opening line and instructions, then choose how it thinks, sounds and listens. Lyre keeps the first step short. You can fill in everything else after the agent exists. For the API view of agents, see the Lyre agents reference.

Create an agent

  1. Open Agents and select New agent.
  2. Enter a Name, for example "Customer support agent", and optionally a Description.
  3. Write the Opening line, the first thing the agent says on a call.
  4. Review the System prompt. It starts with a default you can edit later.
  5. Select Create agent. The agent editor opens.

The agent editor

The editor is split into tabs: Identity Studio, Model, Voice, Transcriber, Tool access, Instructions, Quality, Compliance, Advanced and Share. Changes in Identity Studio save automatically. For every other tab, select Save changes in the top bar. The top bar shows Unsaved changes until you save.

Identity Studio

Identity Studio builds the agent's personality from blocks. Each block covers one part of how it behaves:

  • Core Identity: name, role, traits and description.
  • Call direction: Inbound, Outbound or Both. This decides which opening blocks appear.
  • The Vibe, Conversational Style, Behavioural Rules and Emotional Layering: tone and manner.
  • Regional voice & conversational style: how the agent speaks for your region.
  • Tool capabilities: which tools the agent may use during a call, such as booking a meeting.
  • Compliance, Call Resolution and Fallbacks and SMS behaviour.

Model and voice

  • Model: pick the Provider and Model that drive the conversation. Under First Message Mode, choose whether the agent or the caller speaks first. Set the agent's Timezone, Operating city and Operating country so it talks about dates and places correctly.
  • Voice: choose a voice from Library voices or Your cloned voices. You can search by name, accent or gender. Adjust Stability, Speed and Volume.
  • Transcriber: choose the caller's Language. The options are English (Australia), English (United States), English (United Kingdom) and English (New Zealand). Add Keyterms for names or jargon the agent should hear correctly.

Advanced settings

The Advanced tab holds call handling settings:

  • voicemail for outbound calls, using an AI-generated or a custom message
  • VAD sensitivity and Barge-in threshold (ms), which control how quickly the agent responds and when a caller can interrupt
  • Max call duration (seconds)
  • dual-channel Recording

Give the agent knowledge

  1. Open Knowledge Base, select New knowledge base, give it a Name and select Create.
  2. Drop files onto the knowledge base, or click to browse. It accepts PDF, DOCX, Markdown or plain text, up to 50 MB per file. Each file shows as Pending, Processing, Ready or Failed.
  3. In the agent's Tool access tab, select the knowledge base under Knowledge bases and save.

Teach it playbooks with skills

On the Instructions tab, Add skill creates a playbook the agent loads only when it's relevant. Each skill has a Name, a description of When to use it, and Instructions (markdown). Examples include handling a complaint or explaining your pricing.

Use your own voice

Under Voice clones, select Clone a new voice. Upload a Voice sample in MP3, WAV, M4A or FLAC format (1 to 3 minutes is recommended), give it a Voice name, and confirm the consent checkbox. Only clone a voice you have permission to use. The new voice then appears under Your cloned voices.

Test before going live

  • Talk starts a web call so you can speak to the agent through your microphone. Select End Call to finish.
  • Chat opens a text conversation with the same agent.
  • In Identity Studio, the Test Harness simulates a caller persona so you can see how the agent copes.

Share a public voice link

On the Share tab, you can create a personal voice link for each recipient. Anyone with the link can talk to the agent without signing in. Enter the Recipient name, an optional Message and a Theme, then select Create link.

When your agent sounds right, give it a phone number.

Example instructions for an enquiry agent

State the agent’s role, the information it may use, the questions it should ask and what counts as a successful outcome. For example: answer product questions from the approved knowledge base, gather a callback preference, and escalate when the answer is unavailable. Avoid instructions that promise prices, availability or actions the agent cannot verify.

Test difficult cases as well as the greeting

Try an unknown question, a correction, an interruption and a caller who wants a person. Check the resulting transcript and whether the intended follow-up actually occurred. Change one relevant setting at a time, save it and repeat the same test so you can compare the result.
