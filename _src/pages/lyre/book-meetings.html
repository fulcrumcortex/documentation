A Lyre agent can book a meeting while it's still on the call: it checks your calendar for a free time, offers it to the caller and books it. The supported way to set this up in the dashboard is the Google Workspace connection. It uses a Google service account with domain-wide delegation. That lets the agent check calendars, book meetings and send email as the person you choose.

Connect Google Workspace

You'll need a Google Workspace administrator for one step.

  1. In Google Cloud, create a service account for Lyre and download its JSON key.
  2. In Lyre, open Connections and choose Google Workspace.
  3. Upload the Service account key JSON file.
  4. Under Impersonation, enter the email address the agent should book meetings and send email as.
  5. Tick Book and check calendar, then select Save configuration.
  6. Copy the Domain-wide delegation scopes shown in Lyre. Your Google Workspace administrator pastes them into the Google Admin console for the service account.
  7. Back in Lyre, use Test connection → Run tests to confirm everything works.

For a step-by-step walkthrough of the Google side, see connecting Google Workspace to a Lyre agent. If domain-wide delegation is new to you, this plain-English explainer covers what it can and can't access.

Switch booking on for an agent

  1. Open the agent and go to Identity Studio → Tool capabilities.
  2. Turn on the calendar tools that the Google Workspace connection added: one checks the calendar and one books meetings.
  3. In the agent's instructions or objective, tell it when to offer a meeting, for example "once the caller has confirmed their budget and timing".
  4. Test with Talk and ask the agent to book a time.

Successful bookings show up in call history with the outcome Booking made.

Other calendar tools

Lyre's tools page (Connections → CRM, calendars and tool servers) also lists Calendly and Google Calendar cards. You connect them with a token and then assign them to agents. Availability of these integrations can vary; if a card doesn't connect, use the Google Workspace connection above.

Lyre bookings go into the Google calendar you connect here. They are separate from Fulcrum Calendar booking pages, which people use to book themselves.

A booking test needs a real destination record

Connect the intended calendar account, enable the booking tool for the intended agent and save. Test an available time, an unavailable time and a caller in another time zone. Confirm the event and guest invitation after the call. A spoken agreement is not evidence that the calendar accepted a booking.

When booking fails

Check connection status, calendar access, selected destination, availability and the exact requested time. Inspect tool errors in the call history. Do not tell a caller a meeting is confirmed when the result is still pending or failed; offer a follow-up path instead.
