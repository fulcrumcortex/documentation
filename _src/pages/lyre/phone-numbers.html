A phone number connects a Lyre agent to the phone network. Calls to the number are answered by the agent you assign, and outbound calls and campaigns go out from it. You can buy a new Australian number inside Lyre or bring one you already own.

Buy a new Australian number

  1. Open Phone Numbers and select Add number.
  2. Choose CrazyTel (Australian numbers; buy new or import existing). This is the default.
  3. On Browse & buy, filter by State, City and Number type. The types are local (geographic), mobile, toll-free (1800) and national (13/1300).
  4. Select Search available numbers, then Buy next to the number you want.
  5. Choose the Service address and Registered person for the number, then select Confirm purchase.
  6. Optionally pick an agent under Assign to agent so the number is ready straight away.

Phone numbers carry a monthly charge, shown under Usage & Billing.

Import a number you already have

  • CrazyTel: on Import existing, choose Import next to a number that's already in your CrazyTel account.
  • Twilio: first add your Twilio Account SID and Auth Token on the Providers page. Then choose Twilio, enter the Phone number in international format (for example +61…), pick the agent under Assign to agent, and select Import number.

Assign or change the agent

Each row on Phone Numbers has a dropdown to assign the number to an agent, and another to assign it to a person. The Direction column shows whether the number is enabled for inbound (In) and outbound (Out) calls. When an agent has a number, it can answer inbound calls to that number and use it for outbound calls.

Numbers marked Manage in Cortex belong to Fulcrum Cortex assistants. Change them from Cortex rather than in Lyre.

Recognise known callers

Contacts in Lyre are known callers. When a contact rings, the agent can greet them by name. If you've recorded their consent, you can also set Recording consent confirmed and Skip disclosure by default so regular callers don't hear the AI and recording notice every time. Check that this suits your obligations first; see Compliance.

To bring callers in from another system, Contacts offers Import from HubSpot and Import from Salesforce, once that CRM is connected.

Operators: people on the phones

Operators are the people on your team who place and receive click-to-call bridged calls. Each operator needs a handset and a Lyre number. Invite colleagues to your organisation first, under Organizations → members.

Once a number is live, you're ready to make outbound calls. The Lyre calls API reference covers placing calls from your own software.

Verify inbound and outbound separately

After assigning a number, place a test inbound call and confirm the expected agent answers. For outbound, confirm the selected source number and make an authorised test call to a number you control. A purchased or imported number can still need routing or provider setup before calls work.

When the wrong agent answers

Check the number’s current assignment and the organisation you are editing. Review any imported provider routing and whether the destination was saved. Keep existing working routing intact until you can identify which configuration is actually handling the call.
