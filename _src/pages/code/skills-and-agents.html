Skill or agent?

A skill is a reusable procedure loaded into the conversation when relevant. An agent profile defines a specialist's role and tool set, and can run a focused task in its own context. A Sidekick is an AI teammate; skills describe how that teammate should approach a kind of work. A skill does not grant account permissions or install the service it describes.

Use a skill

  1. Enter /skills to inspect available skills.
  2. Ask for the skill by name and describe the task, for example “Use the refactor skill to simplify this parser while keeping its public API.”
  3. Provide the project constraints and expected checks.
  4. Review the actions and evidence, just as you would for any other agent task.

Write a useful procedure

User skills can live in Markdown files in ~/.fulcrum/skills/. The skill loader supports a name, description and body. Start with a small procedure:

---
name: review-form-change
description: Review a form change before release
---
1. Read the changed form and its validation.
2. Check empty, invalid and valid input.
3. Check keyboard navigation and error messages.
4. Run the relevant existing tests.
5. Report findings and untested behaviour.
Do not publish or change hosted systems.

Use only fictional examples and public project conventions. Do not put tokens or customer details into a reusable skill. Start a new session after changing skill files if they do not appear in the current session.

Discover skill packs

/marketplace provides the available pack management commands. Inspect the pack source and instructions before adding or installing it.

The Sidekick skills repository has 57 skills in 8 plugins: fulcrum-pa-core (personal assistant for any business), fulcrum-property, fulcrum-hospitality, fulcrum-care-workforce, fulcrum-trades-field, fulcrum-professional-services, fulcrum-web-builder, and the fulcrum-sidekicks starter pack for the Fulcrum suite. The starter pack includes skills such as fulcrum-crm-follow-up, fulcrum-voice-agent-setup and fulcrum-booking-setup.

Install in Fulcrum Code

In a Fulcrum Code session:

/marketplace add https://github.com/fulcrumcortex/sidekicks-skills
/marketplace install fulcrum-sidekicks
/skills

The marketplace name and the starter plugin name are both fulcrum-sidekicks. The other packs install the same way by plugin name, for example /marketplace install fulcrum-pa-core or /marketplace install fulcrum-web-builder. Start a new session if the installed skills are not yet listed. To remove the starter pack, use /marketplace remove-plugin fulcrum-sidekicks.

Then ask for a skill by name:

Use the fulcrum-crm-follow-up skill.
Read the latest enquiry for the contact I selected.
Prepare a reply and a next-action suggestion. Do not send it.

Install in Claude Code

Add the repository as a plugin marketplace, then install the packs you want:

/plugin marketplace add fulcrumcortex/sidekicks-skills
/plugin install fulcrum-pa-core@fulcrum-sidekicks
/plugin install fulcrum-web-builder@fulcrum-sidekicks

Install only the industry packs you need, for example fulcrum-property@fulcrum-sidekicks or fulcrum-care-workforce@fulcrum-sidekicks. Run /plugin to browse, update or remove them.

Installing a skill doesn't connect an app, grant permissions or give access to your inbox, customer data or production systems. What an agent can read or change still comes from the tools and account permissions in your host.

Delegate to a specialist

Fulcrum Code includes general, explore and scout profiles. Type @ for the agent and file picker. A request such as @explore find the authentication middleware delegates a focused investigation. Ask for findings with file references and a clear stopping point.

Custom profiles live under ~/.fulcrum/agents/. Define a narrow responsibility and the tools it needs. When several agents contribute, ask the coordinating agent to reconcile their findings before treating the overall task as complete.
