Lists group contacts or companies so you can work on them together, for example everyone tagged "Interested" in Sydney. An Active list is defined by filters and keeps itself up to date. A Static list only changes when you add or remove people.

Create a list

  1. Open Lists and select Create list.
  2. Choose the type, Active or Static, and what it holds: Contacts or Companies.
  3. Add Filters. Conditions inside one group must all match. Separate groups are alternatives, so a record matching either group is included. Active lists need at least one filter.
  4. Enter a List name. Optionally add a description and choose a folder.
  5. Select Create list.

Active lists refresh automatically every 15 minutes, and you can select Refresh to update one straight away. Custom fields can be used as filters too; see Custom fields.

Work with a list

Open a list to see its members. From there you can:

  • Import CSV to add people, or Export CSV to download the list. Export is limited to owners by default.
  • Clone the list as a starting point for a new one.
  • Convert to static to freeze an active list as it is now.
  • Remove from list for selected members, or Delete the whole list.

On the Lists page, a list's ••• menu adds Move to folder and Rename. You can also add contacts to a list straight from the Contacts page: select them and choose Add to list.

Lists and campaigns

Lists are one of the ways to choose who receives an email campaign. Campaigns also have their own saved segments under Campaigns → Segments; see Campaigns and newsletters.

Choose static or active for the job

A static list is useful for a deliberately selected cohort, such as people attending a particular event. An active list follows its saved conditions, so membership can change as records change. Review a sample of matching and non-matching contacts before using an active list for a campaign.

Before acting on a list

Check whether you selected only the visible page or every matching record. Confirm the audience and exclusions, particularly after updating filters. List membership does not override suppression, unsubscribe state or contact permissions. Keep a record of the selection criteria for repeat campaigns.
