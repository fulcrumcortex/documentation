Connect an external service

  1. Open Integrations and choose the intended service.
  2. Read the access requested and authenticate with the correct provider account.
  3. Return to CRM and inspect the saved connection and status.
  4. Run a small permitted test of the exact workflow you need.
  5. Verify the destination record or delivery result.

Signing in, reading records and writing records can require different scopes. A connected badge is only one part of the check. If credentials are revoked at the provider, reconnect through the supported flow rather than copying tokens into chat.

Connected apps and MCP

Review each app’s purpose and access. Use tool logs to diagnose the action, target and outcome when an assistant cannot complete a task. Logs can contain customer information, so redact them before sharing. Revoke credentials no longer needed and check that dependent workflows have an alternative before disconnecting a shared integration.

Public chat

Review the customer-facing instructions, supported knowledge and available actions before embedding a chat experience. Test it in a signed-out window with fictional data and verify the resulting enquiry or record. Do not assume a public visitor has the same authority as a signed-in employee.

Keep configuration changes reviewable

Change one relevant setting at a time and verify its effect. Record the previous value when a change could interrupt a team workflow. Check the selected organisation before changing business details, integrations or shared credentials.
