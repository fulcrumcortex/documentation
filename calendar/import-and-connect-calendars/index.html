Import and connect calendars

Copy events into the Fulcrum Calendar from an .ics export, create extra Fulcrum calendars, and connect Google or Microsoft calendars for booking availability.

There are two ways to bring other calendars into Fulcrum, and they do different jobs. Importing copies the events from another calendar into the Fulcrum Calendar once. Connecting a Google or Microsoft account doesn't show its events in your Fulcrum Calendar. Fulcrum uses a connected calendar to check when you're busy and to add new bookings to it from your booking pages.

Import a calendar file

Most calendar apps, including Zoho, Google and Outlook, can export your events as an .ics file.

  1. Export your calendar from your current app as an .ics file. For Zoho, follow the Export from Zoho Calendar help inside the import dialog.
  2. In Fulcrum Calendar, select Import calendar in the sidebar.
  3. Choose your Calendar file (.ics). It must be smaller than 2 MB.
  4. Under Import into, choose New imported calendar or an existing calendar. For a new calendar you can give it a name.
  5. Set the Time zone for events without a time zone.
  6. Select Preview import and check the count of events, recurring series and skipped items.
  7. Select the import button to finish, or Change file or settings to go back.

What an import does and doesn't do

  • It's a one-time copy. It doesn't keep the old calendar in sync, and it doesn't send invitations to guests.
  • Importing the same file into the same calendar again skips events you already have and keeps any edits you made.
  • Repeating events that repeat daily, weekly, monthly or yearly are kept.
  • Reminders from the export are kept with the events but don't fire in Fulcrum yet.
  • Editing an imported event changes it in Fulcrum only, and no invitations go out. When you delete an imported repeating event, you can choose Only this occurrence or Entire series.

Create another Fulcrum calendar

Extra calendars are handy for keeping bookings of one kind together, such as consultations.

  1. In Calendar, select Booking pages, then open the Connected calendars tab.
  2. Under Fulcrum calendars, enter a New calendar name.
  3. Select Create calendar.

You can have up to 30 calendars, and each name must be different.

Connect a Google or Microsoft calendar

  1. In Calendar, select Booking pages and open Connected calendars. (In Settings → Connected calendars, the same choice appears as Connect Google and Connect Microsoft.)
  2. On the Google Calendar card (Gmail and Google Workspace) or the Microsoft Outlook card (Microsoft 365 and personal Outlook), select Connect account.
  3. Sign in to that provider and approve the calendar permissions. Fulcrum needs them to check your availability and add bookings.

If a card shows Connection setup pending, that provider isn't available yet. Each connected account appears with its email address and status. If the status reads Reconnect required, select Reconnect.

Use this provider to sign in is a different option. It lets you sign in to Fulcrum with that Google or Microsoft account, and it doesn't connect any calendars.

Disconnect a calendar

Select Disconnect next to the account. Any booking page that uses that calendar is unpublished, either to check for conflicts or as the place new bookings go. You can't disconnect a calendar while upcoming bookings are still being added to it. Complete or cancel them first; see Manage bookings.

Lyre voice agents book through their own Google Workspace connection, not this one. See Book meetings with a Lyre agent.

Choose import or connection deliberately

Import a calendar file for a snapshot of events. Connect an account when you need supported provider-backed availability and booking behaviour. Reimporting the same file can create confusing duplicates, so inspect a sample of events before repeating an import.

Check the provider connection

Confirm the provider account, requested access and connection status. Sign-in through Google or Microsoft does not by itself mean Calendar has permission to check that provider’s events. After connecting, select the calendar for conflict checking in the booking page and test a known busy time.
